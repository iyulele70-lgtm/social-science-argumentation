# 著作与论文的论证还原模式

用于分析一本社会科学著作、一篇论文或某个章节“如何从研究问题推导到研究结论”。重点是重建证明结构，不是复述内容或评价文笔。

## 目录

1. 资料读取与证据定位
2. 找到总问题和核心答案
3. 重建问题树
4. 判断章节功能
5. 识别承重论证
6. 还原机制和推理方式
7. 解释证据如何工作
8. 检查竞争解释和边界
9. 局部问题分析
10. 课程作业结构

## 1. 资料读取与证据定位

### 先建立文本地图

优先检查：目录、序言或导论、作者明确提出问题的位置、理论或概念章节、关键经验章节、结论。不要默认章节标题就是研究问题。

记录每项关键判断的来源位置：页码优先，其次是章、节或电子书位置。区分：

- 作者明说的问题或主张；
- 根据多处文本重建的问题或前提；
- 分析者对论证强弱的评价。

若文本为扫描件，抽查 OCR 容易误识别的数字、专名、否定词和段落边界。无法稳定定位时，不制造精确页码。

### 先整体、后局部

第一次阅读寻找全书任务和结构；第二次围绕承重论证定向取证。不要试图平均摘要每一章。

## 2. 找到总问题和核心答案

总问题可能不是一句现成问句，需要通过以下线索重建：

- 作者反复指出的异常或矛盾；
- 被批评的常识或既有解释；
- 各章共同指向的结果变量；
- 导论承诺解释什么；
- 结论声称已经回答什么。

用以下形式记录：

> 观察到的现象是 `[Y]`；按 `[常识/理论 R]` 本应出现 `[O1]`，实际却出现 `[O2]`。作者要回答 `[Q]`，其核心答案是：在 `[S]` 条件下，`[X]` 通过 `[M]` 造成或促进 `[Y]`。

检查导论中的承诺、经验章节中的实际证明与结论中的宣称是否一致。若不一致，分别记录“作者宣称的问题”和“文本实际解决的问题”。

## 3. 重建问题树

把全书论证分为总问题与必要分问题：

| 层级 | 常见功能 |
|---|---|
| Q0 | 全书最终解释什么 |
| Q1 | 证明待解释现象确实存在 |
| Q2 | 说明主流解释为何不足 |
| Q3 | 重新界定概念或分析单位 |
| Q4 | 提出并展开核心机制 |
| Q5 | 用比较、历史或统计材料验证机制 |
| Q6 | 排除竞争解释或处理反例 |
| Q7 | 说明一般化范围与边界 |

并非每本书都有全部层级。只保留实际承担证明任务的分问题，不为结构整齐虚构问题。

## 4. 判断章节功能

对每章不要只问“讲了什么”，而要问“它使总论证向前推进了哪一步”。常见章节功能包括：

- 提出谜题；
- 批评旧解释；
- 定义概念或确定分析单位；
- 建立背景条件；
- 说明机制的某个环节；
- 提供比较证据；
- 检验反例或替代解释；
- 限定边界；
- 汇总和推广结论。

每章写出：分问题、阶段答案、关键证据、推理方式、阶段结论、与下一章的关系。

警惕两种误判：

- 章节在时间上先出现，不代表它在因果链中是最初原因；
- 作者花费篇幅多，不代表该内容在总论证中最承重。

## 5. 识别承重论证

优先分析三至五个承重单元，而非平均分配篇幅。判断标准：

1. 它是否构成核心机制不可缺少的一环？
2. 后续多个章节是否以它为前提？
3. 如果它不成立，总结论是否明显受损？
4. 它是否承担排除最强替代解释的任务？

为每个单元建立 `Q–A–P–C–M–E–R–L–T–B` 卡片。原文没有的部分写“未明确处理”，不要替作者补齐。

## 6. 还原机制和推理方式

### 机制重建

将作者解释写成：

`背景条件 S → 起始因素 X → 行动者反应 M1 → 互动/组织过程 M2 → 中间状态 Z → 结果 Y`

逐个箭头查找证据。若作者只展示 X 与 Y 同时存在，而没有 M 的材料，只能说建立了关联或提出了机制，不能说机制已被证明。

### 判断推理方式

| 方式 | 识别线索 | 需要检查 |
|---|---|---|
| 演绎 | 从理论前提推出命题，再用材料检验 | 前提是否成立、命题是否真的由前提推出 |
| 归纳 | 从多个观察形成模式和一般判断 | 样本是否足以推广、是否挑选材料 |
| 溯因 | 多种解释竞争，作者选择最佳解释 | 是否比较了真正强的替代解释 |
| 比较 | 利用案例共同点或差异识别原因 | 案例是否可比、是否遗漏关键差异 |
| 过程追踪 | 按时间重建原因到结果的中间事件 | 是否只有连贯叙事而无区分性证据 |
| 反事实 | 讨论若无 X，Y 是否仍会发生 | 反事实是否受历史或比较证据约束 |

一本著作通常混用多种方式。指出哪一章主要使用哪种推理，以及它承担的证明任务。

## 7. 解释证据如何工作

把证据按功能分类：

- `D`：证明现象存在、规模或分布；
- `C`：证明关系和时序；
- `M`：证明机制中间环节；
- `X`：削弱或排除竞争解释；
- `K`：反例、异常或负面案例；
- `S`：确定结论适用边界；
- `T`：不同来源三角互证；
- `B`：连接微观行动和宏观结果。

分析证据时回答：

1. 这项材料支持哪一个具体命题？
2. 从材料到命题依赖什么推理桥梁？
3. 它只说明存在、相关，还是能说明因果或机制？
4. 它与其他证据是否独立？
5. 有没有同样能够解释该材料的替代理论？
6. 作者是否选择性忽略不利材料？

评价证据用“强、中、弱”时必须说明理由，不能只贴等级。

## 8. 检查竞争解释和边界

至少检查：

- 作者明确反对了哪些解释？
- 是否把弱版本的对手当成全部对手？
- 是否处理反向因果、共同原因和案例选择？
- 是否存在与核心命题不一致的案例？
- 作者怎样解释例外？是修正机制、增加条件，还是忽略？
- 结论从哪些样本推广到哪些对象？这一步是否有依据？

评价时采用两步法：

1. **内部有效性**：如果接受作者的前提，证据能否推出结论？
2. **外部有效性**：即使书中案例成立，能否推广到作者声称的更大范围？

## 9. 局部问题分析

用户只询问某章、某一制度或一个具体悖论时，使用简化流程。

### 输出结构

1. **直接答案**：一至两句话。
2. **问题为何成立**：指出表面矛盾或既有预期。
3. **作者的关键区分**：说明概念重定义或分析层次转换。
4. **三至五步推理链**：每一步说明前提和结果。
5. **证据或例证的作用**：不做无关摘要。
6. **限制**：作者没有证明什么，或结论受何条件限制。

### 分析段落支架

> 作者在 `[章节]` 处理的问题是 Q。它之所以构成谜题，是因为解释 R 预期 O1，而文本呈现 O2。作者通过概念 C 重新界定对象，提出答案 A，并将机制写为 X→M→Y。证据 E1 支持其中的 `[事实/时序/机制]`，E2 用于削弱解释 R。由此能推出阶段结论 L，但尚不能推出 O，因此更稳妥的边界是 B。

若用户要求“根据某章回答”，答案必须以该章论证为主；可用其他章节补充，但要明确标注来源不同。

## 10. 课程作业结构

对于“分析一部著作的论证逻辑”类作业，推荐以下结构。字数按总篇幅调整，不必机械固定。

| 部分 | 证明任务 | 约占篇幅 |
|---|---|---:|
| 引言 | 界定分析对象、任务和总判断 | 8%–10% |
| 总问题与核心答案 | 重建谜题、主张和总体机制 | 12%–15% |
| 概念、前提与文献对手 | 说明作者怎样重构问题 | 12%–15% |
| 承重论证一 | 分析第一关键推理单元 | 15%–18% |
| 承重论证二 | 分析第二关键推理单元 | 15%–18% |
| 承重论证三 | 分析机制、比较或跨章连接 | 15%–18% |
| 整体评估 | 证据强度、替代解释、边界与跳跃 | 12%–15% |
| 结论 | 回答“本书怎样论证”及其有效范围 | 6%–8% |

### 正文写作要求

- 每一节开头写本节要回答的分问题。
- 每一节用一句话给出作者的阶段答案。
- 随后分析概念、前提、机制和证据如何联合工作。
- 章末写阶段结论以及它怎样成为后文前提。
- 评价应紧跟具体推理单元，最后再做总体汇总。

### 不合格倾向

- 大量介绍作者生平和时代背景；
- 按章节依次复述内容；
- 只概括作者观点，不分析证据和推理；
- 只说“论证严密”“材料丰富”，不给判断依据；
- 用今天的价值判断替代对作者解释逻辑的检验；
- 只寻找错误，不先完成善意而准确的论证重建；
- 在结论中提出正文未分析的新批评。
