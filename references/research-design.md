# 研究设计模式

用于把一个社会科学主题发展为可检验、可写作的研究方案。目标不是替用户虚构研究，而是暴露并补齐从问题到结论之间缺失的推理环节。

## 目录

1. 确定知识目标
2. 从现象形成谜题
3. 建立问题树
4. 绘制文献解释地图
5. 界定概念与分析层次
6. 提出核心答案与机制
7. 设置竞争性解释
8. 推导命题和可观察预期
9. 匹配研究设计
10. 规划证据
11. 组织章节和段落
12. 写结论与贡献

## 1. 确定知识目标

先识别主要论文类型。若同时具备多种目标，确定主目标，其他目标从属于它。

| 类型 | 核心问题 | 主要结论形态 | 关键风险 |
|---|---|---|---|
| 描述型 | 什么现象存在，如何分布或变化？ | 经验证实的模式 | 测量和样本失真 |
| 因果解释型 | 为什么发生，X 是否影响 Y？ | 原因、机制与条件 | 混淆、反向因果 |
| 意义理解型 | 行动者怎样理解并采取行动？ | 意义结构与行动逻辑 | 脱离语境、过度解释 |
| 比较历史型 | 为什么不同案例或时期出现差异？ | 路径、序列与关键节点 | 不可比、目的论 |
| 理论型 | 现有概念或理论为什么不足？ | 新概念、新命题或理论修正 | 概念含混、不可检验 |
| 政策型 | 在明确价值目标下应采取什么方案？ | 后果判断与政策建议 | 混淆事实、因果和价值 |

记录：

- 主要类型：`[...]`
- 研究对象：`[...]`
- 希望增加的知识：`[...]`
- 主要学术受众：`[...]`
- 读者读后应改变的认识：`从……变为……`

## 2. 从现象形成谜题

研究谜题来自预期与事实的张力，而不只是“问题很重要”。优先寻找：

- 理论预期 A，现实出现 B；
- 条件相近的案例产生不同结果；
- 条件不同的案例产生相似结果；
- 多个理论对同一现象给出不同机制预期；
- 一个制度或结果持续存在，违背效率、利益或常识预期。

填写：

> 已知 `[常识、理论或一般趋势]`，按理应出现 `[预期]`；然而在 `[时间—空间—对象]` 中观察到 `[事实]`。既有解释 `[R]` 不能充分说明这一偏离，因此需要回答 `[为什么/如何]`。

若只能写出“这一现象很重要”或“该地区研究较少”，尚未形成谜题。

## 3. 建立问题树

主问题只保留一个核心关系。分问题是回答主问题所必需的论证步骤，不是并列的兴趣点。

| 层级 | 典型任务 | 输出 |
|---|---|---|
| Q0 | 为什么/如何出现核心现象？ | 核心答案 A0 |
| Q1 | 待解释事实是否存在，形态如何？ | 描述性结论 A1 |
| Q2 | 既有解释为什么不足？ | 理论空间 A2 |
| Q3 | 关键因素通过什么机制起作用？ | 机制结论 A3 |
| Q4 | 为什么不是其他解释？ | 排除性结论 A4 |
| Q5 | 何时成立、何时失效？ | 边界结论 A5 |

问题质量门：

- 对象、结果、时间与空间是否明确？
- 能否用可获得的材料回答？
- 答案是否可能被事实修正？
- 回答后是否会改变对一类现象的认识？
- 是否混入了两个以上不能用同一设计回答的问题？

## 4. 绘制文献解释地图

文献综述必须交付三项结果：已知什么、不同解释怎样竞争、本文推进什么。

按解释路径而不是作者姓名组织文献。为每条路径提取：

- 回答的具体问题；
- 核心答案和机制；
- 证据与方法；
- 适用范围；
- 无法解释的事实；
- 本研究与它的继承、修正或竞争关系。

有效缺口包括：解释缺口、发现冲突、理论边界不明、机制缺失、概念混淆、缺乏区分竞争解释的证据。

收束文献综述时使用以下逻辑，而非照抄措辞：

> 路径 R1、R2 已经解释 K，但共同预设 P，因此无法说明谜题 Y。本文考察 X 如何通过 M 改变 Y，进而说明原解释在条件 S 下的适用边界。

## 5. 界定概念与分析层次

为每个承重概念写出：

- 理论定义；
- 明确不包括的相邻现象；
- 经验识别线索或操作化；
- 分析层次；
- 在全文中的固定含义。

同时限定：时间、空间、研究对象和机制运行条件。

检查跨层次推理：若用个体动机解释组织或制度结果，必须说明个体行动如何聚合；若用宏观关系推断个体行为，必须提供连接机制，避免生态谬误。

## 6. 提出核心答案与机制

核心答案必须是可争辩的判断，不能写成研究目的。

填写：

> 在条件 S 下，X 并非直接造成 Y；X 首先改变 M1，继而通过 M2 影响 Y。与竞争解释 R 不同，本解释还预期观察到 O1、O2。

机制链至少回答：

1. 谁是行动者？
2. X 改变了什么资源、机会、激励、认知或约束？
3. 行动者为何做出相应选择？
4. 互动过程怎样形成中间状态？
5. 微观行动如何聚合为宏观结果？
6. 每个环节会留下什么可观察痕迹？

区分必要条件、充分条件、促进因素、触发因素、背景条件、中介机制和调节条件。社会科学中的常见结论是概率性且有条件的，不应轻易写成必然决定。

## 7. 设置竞争性解释

至少建立以下替代解释清单：

- 反向因果：Y 导致 X；
- 共同原因：Z 同时影响 X 与 Y；
- 选择过程：观察到关系是因样本或案例选择造成；
- 测量解释：所谓变化来自指标变化；
- 替代机制：X 确实相关，但通过另一机制产生 Y；
- 偶然或特例：关系只存在于特殊案例。

对每个解释写出其独特的可观察预期。无法用现有设计区分时，将其作为明确限制，而非口头宣称已经排除。

## 8. 推导命题和可观察预期

定量研究可写统计假设；质性、历史或理论研究使用命题与可观察预期。每项命题应包含：

- 方向或关系；
- 机制依据；
- 成立条件；
- 分析层次；
- 支持时应观察到什么；
- 反证或修正条件。

不要在看到结果后才倒推一个永远不会失败的假设。

## 9. 匹配研究设计

先写“需要证明或区分什么”，再选择方法。

| 证明任务 | 可考虑的设计或材料 | 首要风险 |
|---|---|---|
| 描述分布与变化 | 调查、统计、档案编码 | 测量和代表性 |
| 识别因果关系 | 实验、准实验、面板、严谨比较 | 混淆和反向因果 |
| 识别中间机制 | 过程追踪、访谈、档案、机制变量、多方法 | 只见结果不见过程 |
| 理解行动意义 | 深访、观察、文本或话语分析 | 去语境化 |
| 解释历史路径 | 档案、事件序列、比较历史分析 | 后见之明和目的论 |
| 解释案例差异 | 最相似/最不同案例、嵌套分析 | 案例不可比和选择偏差 |

设计说明必须回答：为什么这些案例、样本、时期或文本能区分本文解释与替代解释？

## 10. 规划证据

为证据分配明确功能：

- `D` 描述或存在；
- `C` 关系、时序或因果关联；
- `M` 机制过程；
- `X` 排除竞争解释；
- `K` 反例或负面证据；
- `S` 适用边界；
- `T` 多来源三角互证；
- `B` 连接微观与宏观层次。

每项证据检查相关性、充分性、独立性、可靠性和可反驳性。多个二手来源若追溯到同一原始材料，只算一个证据来源。

## 11. 组织章节和段落

章节由证明任务决定，不由材料类别决定。每章先写六个句子：

1. 本章回答的分问题；
2. 本章的直接答案；
3. 核心机制；
4. 关键证据；
5. 要处理的反驳；
6. 阶段结论怎样引出下一章。

段落使用“主张—必要界定—证据—推理桥梁—限定—过渡”。证据后必须解释为什么它支持本段主张。

## 12. 写结论与贡献

结论依次完成：

1. 直接回答主问题；
2. 汇总关键发现，而非加入新证据；
3. 说明相较既有解释改变了什么认识；
4. 指出证据支持到什么程度；
5. 交代时间、空间、对象和条件边界；
6. 提出能够继续检验的后续问题。

区分经验贡献、机制贡献、理论修正和概念贡献。新对象、新资料或新方法只有在产生新的知识判断时才构成贡献。

## 分阶段交付建议

用户需要共同规划时，采用以下检查点：

1. 先交付“谜题 + 主问题 + 一句话答案”；
2. 用户确认后交付“文献解释地图 + 机制 + 竞争解释”；
3. 再交付“研究设计 + 证据计划 + 章节提纲”；
4. 最后才进入正文写作。

用户明确要求一次性方案时，可合并交付，但仍应在文中标明哪些环节已确定、哪些仍是待验证假设。
